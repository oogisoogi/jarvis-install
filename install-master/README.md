# install-master — 자비스 설치 도우미

| 파일 | 무엇 |
|---|---|
| `bootstrap.sh` | 맥 설치 도우미 |
| `bootstrap.ps1` | 윈도우 설치 도우미 |
| `reinstall.sh` · `reinstall.ps1` | 다시 설치 |
| `reset-clean.sh` · `reset-clean.ps1` | 설치가 남긴 것 지우기 |
| `command-table.json` | 원격 해결 허용 명령 표(설치 도우미 안에 넣어 둔 표의 대조용 사본) |
| `footprint.md` | 설치가 이 컴퓨터에 남기는 것 전부 |
| `checks.sh` | 「되돌리면 빨개지는」 검사 모음 |

## 원격 해결

설치가 막혀 멈추면, 설치 창이 진단을 서버로 보내고 창을 연 채 운영팀의 처방과 명령을 기다립니다.
서버 쪽 계약은 ai-jarvis `web-install/docs/HELP-API.md`(4·5·7·9절)가 정본입니다.

### 언제 도는가

- `[1/10]` 에서 고지 한 줄을 보여 드린 실행에서만 돕니다(누를 것은 없습니다).
  「막히면 진단이 서버로 가고 운영 자비스가 원격으로 해결합니다 · 창을 닫으면 멈춥니다 · 자세히: jarvis-install.godmeyou.kr/help/notice」
- 진단 코드(J-코드)를 남기고 끝난 자리에서 돕니다. 자비스를 **깨우는 데 성공한 뒤에는** 돌지 않습니다 —
  깨우기 자체가 실패하면(클로드를 못 찾음 · 창을 못 엶) 원격 해결이 돕니다.
- 미리보기(`--dry-run` · `-DryRun`)는 보내지 않습니다.

### 무엇을 보내는가

- 진단 코드 · 멈춘 단계 · 운영체제 · 설치 도우미 판본 · 환경 보고 앞부분 · 기록 끝 200줄.
- 보내기 전에 이 컴퓨터에서 먼저 지웁니다: 집 폴더 경로 · 이메일 · 토큰·키 · 로그인 이름(서버가 한 번 더 지웁니다).
- 본문은 직렬화한 JSON 을 재어 240,000 바이트 안으로 줄여 보냅니다(서버 상한 256KB).

### 운영팀 명령은 어떻게 실행되는가

1. 서버 응답을 믿지 않습니다 — 설치 도우미 안에 넣어 둔 **허용 명령 표**(읽기 13종)로 글자·칸 수·이름·모양을 다시 잽니다. 표 밖이면 실행하지 않고 거절을 돌려줍니다.
2. 경로 칸은 작업 폴더(`install-jarvis`) 안이어야 합니다. 링크·정션을 풀어 실제 경로로 재고, 없는 폴더 안의 이름은 열지 않습니다.
3. **파일은 먼저 열고, 연 것이 맞는지 확인한 뒤, 연 것을 읽습니다** — 확인과 읽기 사이에 이름을 링크로 바꿔 끼워도 따라가지 않습니다.
   - 맥: fd 3 으로 열어 그 파일과 이름이 가리키는 파일의 장치·아이노드가 같을 때만 `/dev/fd/3` 을 명령에 줍니다(폴더는 그 안으로 들어가 같은지 대조한 뒤 `.`).
   - 윈도우: 읽기 핸들을 먼저 열고(지우기·이름 바꾸기를 막는 공유 방식) 다시 확인한 뒤 그 핸들로 읽습니다. 폴더 목록은 핸들로 읽을 수 없어 다시 확인까지만 합니다.
4. 명령은 실행 **전에** 설치 창에 그대로 찍힙니다.
5. 실행한 명령 번호를 실행 **전에** 파일(`remote-help-executed.json`)에 남깁니다 — 재부팅 뒤에도 같은 번호는 다시 돌지 않습니다. 두 창이 동시에 남기지 못하게 잠급니다(맥 = 잠금 폴더 · 윈도우 = Mutex). 기록 파일이 깨졌으면 아무것도 실행하지 않습니다.
6. 셸을 거치지 않고 실행합니다(프로그램 + 인자 배열 · cmdlet + 매개변수 표). 명령 하나는 60초까지 · cys 데몬을 깨우지 않습니다(`CYS_NO_AUTOSTART=1`).
7. 결과는 끝 4KB 만, 같은 규칙으로 지운 뒤 돌려줍니다.

### 멈추기

- 설치 창을 닫으면 멈춥니다. 맥은 창이 닫힐 때(HUP)·중단(INT·TERM) 때 닫기를 보내고, 윈도우는 원격 해결이 어느 길로 끝나도(중단 포함) 닫기를 보냅니다.
- 보고 화면의 「원격 해결 멈추기」 · 명령이 30분 없음 · 시작 2시간 · 서버가 닫음(410) · 보고 지움(404)에서도 멈춥니다.
- 끝나면 「원격 해결이 끝났습니다」와 함께 아래에 「다시 하시는 법」이 나옵니다.

### 남는 파일

`remote-help-executed.json`(실행 번호) · `remote-help-client-token`(출처 토큰 · 본인만 읽기). 본인만 읽는 권한을 걸지 못하면 토큰을 파일에서도 메모리에서도 버리고 출처 헤더 없이 보냅니다. 자세한 표 = `footprint.md`.

### 한계(정직)

- 작업 폴더 안에 **밖 파일의 하드 링크**가 있으면 같은 파일로 읽힙니다 — 그것을 만들 수 있는 계정은 명령 없이도 그 파일을 읽습니다.
- 맥의 기록은 임시 파일에 쓴 뒤 이름을 바꿉니다(반쯤 쓴 파일 없음). 디스크 전체를 비우는 `sync` 는 쓰지 않으므로, 쓴 직후 전원이 끊기면 기록이 사라질 수 있습니다.
- 윈도우: 폴더 목록의 여는 순간 교체 · 정션·8.3 짧은 이름 · 강제 종료 때 닫기 · 핸들 읽기의 시간 상한은 윈도우 실기에서 확인해야 합니다.

### 시험

```bash
bash tests/remote-help-run.sh                 # 맥 — 설치 도우미를 함수 묶음으로 읽어 실제로 부른다(가짜 서버)
python3 tests/remote-help-mutate.py           # 맥 뮤턴트 — 관문 하나씩 지워 그 시험이 빨개지는지
python3 tests/remote-help-ps1-static.py       # 윈도우 — 정적 검사
python3 tests/remote-help-ps1-static.py --mutants
bash install-master/checks.sh
```
