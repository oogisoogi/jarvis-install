# 막혔을 때 — 진단 코드 안내 (초안 · 2026-09-09)

> 이 문서는 **사이트 코드 페이지의 초안**이다. 게시는 관리자가 한다(`/help/<코드>`).
> 정본 표 = `tests/help-rules.tsv` — 이 문서는 그 표에서 옮겨 적은 것이고, 둘이 갈리면 검사기가 붉어진다.
>
> 설치 도우미는 멈출 때 화면에 **코드 한 개**를 적는다. 같은 코드가 세 자리에 남는다 —
> 화면 · 환경 보고(`env-report.md`) · 기록 파일(`bootstrap.log`).
> 코드를 그대로 읽어 이 페이지에서 찾으시면 된다.

**코드 읽는 법** — `J-<어디>-<번호>`
`AV` 백신 · `NET` 연결 · `RM` 지난 설치 자국 · `PATH` 명령 못 찾음 · `LOGIN` 로그인 ·
`PERM` 권한 · `DISK` 저장 공간 · `VER` 판본 · `DL` 받은 파일 확인 · `UNK` 아직 분류 못 함

이 도구가 만들고, 지울 때 통째로 지우는 폴더의 이름은 **`install-jarvis`** 하나입니다.
그 이름이 아닌 자리나, 이미 다른 파일이 들어 있는 폴더는 **채택하지 않습니다** —
지울 때 그 안의 것을 함께 잃기 때문입니다.
