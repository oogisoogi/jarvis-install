# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Email **oogisoogi@gmail.com** with a description, the affected file (or the installer version shown on the first screen), and steps to reproduce.

The supported version is the latest commit on `main` — the installer scripts are always served from there.

## 보안 문제 알리기

보안 문제는 공개 이슈로 올리지 마시고 **oogisoogi@gmail.com** 으로 알려 주십시오.
문제 설명 · 해당 파일(또는 첫 화면에 보이는 설치 도우미 판번) · 재현 방법을 적어 주시면 됩니다.
